FIND A PLAYER

Remove score takes a player's scores off the public boards. It keeps their FLUX ID and purchases — and they can post new scores. For repeated abuse, use Restrict: they keep playing, but nothing they submit appears publicly. Restrictions follow a player's device identity; if they clear their browser data, they return with a new tag.

PLAYER STATS

Anonymous, counted on our own server. See the guide below for what each number means.

SEASON 0 SCORES (ARCHIVED)

Read-only. Every best from before Season 1, kept when the boards were reset. Nothing here is public.

BACKUPS

The leaderboard (scores, pilots, purchases, restore log, bans, season archive) is copied every day and each copy is checked. Restoring is never automatic. See Backups and restore in the guide below.

Have a downloaded backup file? Upload it here; it is checked, then listed like any other backup.

STORAGE

How the leaderboard is kept on the server. The old layout keeps every pilot in one stored value that Cloudflare caps at 2 MB (about 8,000 pilots); past that, every score upload fails. The new layout keeps one row per pilot and works far beyond 200,000 pilots on the free plan. You move it once, in the steps below. Nothing happens by itself. See Storage move (2 MB limit) in the guide.

WORLD GRID

One World Grid from the Season 0 archive and Season 1: each pilot's best of both, counted once. DRY RUN changes nothing. Applying needs a checked backup from the last hour and the phrase the dry run shows. It works on the new storage layout only: move the storage first (STORAGE). See Combined World Grid in the guide below.

GUIDE

A player lost their pilot

  1. Ask for their pilot name and, if they can see it, the #TAG next to it on the leaderboard (for example SWIFT COMET 42 #K7Q2MX8). Also ask their country and roughly their best score.
  2. Type the name in FIND A PLAYER (upper or lower case both work; "SWIFT COMET 42 #K7Q2" finds that exact pilot). Check the country and scores match what they told you. For a pilot with purchases, their Stripe receipt email must match (look it up under ADVANCED, in the purchase records section).
  3. Press ISSUE RESTORE CODE and write how you checked them. Copy the code and send it to them privately. It is shown once and not stored.
  4. They open FLUX → EDIT → HAVE A RESTORE CODE? (if that button says RESTORE CODE, tap it, then RESTORE A DIFFERENT PILOT) and paste the code. Their pilot, scores and skins come back.

Removing test pilots (and what to do about a cheater)

Remove score takes a pilot off every public board and out of the country totals. It is meant for your own test pilots and mistakes. Restrict is for a suspected cheater: they keep playing, but nothing they submit shows publicly, and you can lift it any time with UNRESTRICT. PRIVACY DELETE is only for a player's deletion request: it erases everything, also from backups, and cannot be undone.

  1. Back up first: BACKUPS → BACK UP NOW. Wait for the new backup to show ✓ (verified).
  2. Note the country total: in the game, LEADERBOARD → WORLD, write down your country's points (the board refreshes about once a minute).
  3. Find the exact pilot: FIND A PLAYER → type the name and its #TAG, e.g. TITAN #QGAC1ZN → FIND. Check the card shows that exact #TAG. Never act on a card whose #TAG you did not type: pilots can share a name.
  4. Remove it: on that card press REMOVE SCORE, read the box, press OK. Repeat for each test pilot.
  5. Check: FIND the same name and #TAG again: it should say nothing was found. After a minute, LEADERBOARD → WORLD: your country's total dropped by that pilot's counted score. Look up your real pilot too and make sure it is still there.

Season 0 scores: with the combined World Grid on, a removed pilot's Season 0 bests leave the boards and the country totals too. Don't play on a removed test pilot again: if it posts a new score, its Season 0 bests come back with it.

Removed the wrong pilot? There is no "un-remove" button. Do this at once: BACKUPS → SHOW BACKUPS → on the backup you took in step 1 press DRY RUN (it changes nothing and lists what a restore would change) → if it only brings that pilot back plus the few minutes since, type the phrase shown (RESTORE …) and press RESTORE NOW. A restore puts back everything as it was at that backup, so scores other players posted since then are lost: that is why you back up right before removing, and restore right away.

Spotting test pilots: names like TEST, TESTER, QA, ADMIN or your own name with a different #TAG; pilots from your country that played only on the days you were testing; several pilots with the same name. Search the name alone (e.g. TITAN) to see every pilot using it, then decide by #TAG.

Pilot names

  • Every new pilot starts with a preset name from a safe word list, like SWIFT COMET 42.
  • In EDIT a player may type their own name: one word, letters and numbers only, up to 12 characters. Full names, spaces, and anything that looks like an email, phone number or web link are refused; the box goes back to their current name and play is never blocked.
  • A rude or impersonating name, or one you banned under NAME BANS, shows as PILOT on the board. The card here shows its real name with a pink "SHOWN AS PILOT" label. Searching "PILOT" finds them too.
  • Old-name clean-up: names typed before these rules that break them were switched to the pilot's preset, and their old text was deleted from the server once. You cannot find a pilot by an old deleted name; ask for the name they see now.

Season 1 reset

  • When the Easy and Medium point rates changed, old bests could no longer be beaten, so every board (Easy, Medium, Hard and All) was reset once for Season 1. It ran by itself on the first request after that update.
  • Every old best was copied first: SEASON 0 SCORES (ARCHIVED) lists them (difficulty, pilot, country, score, level, date), highest first. It is read-only and never shown to players. A privacy deletion removes the pilot there too.
  • Only scores were reset. Pilots, names, #tags, countries, skins, purchases, restore codes, restrictions, name bans and stats are unchanged. Players who had played before see "Season 1: new point rates on Easy and Medium." once; their phone's old bests are cleared to match.
  • A game page left open from before Season 1 cannot post old-rate scores; it is refused until the page reloads.

Backups and restore

  • Every day (first check after midnight UTC) the server copies the whole leaderboard: pilots and their bests on every difficulty, purchases (skins), the restore-code log, restrictions, name bans, flags, country figures and the Season 0 archive. Each copy is read back and checked straight away; BACKUPS shows ✓ for a good copy and ✗ for one that failed. If a day's backup fails it is tried again on the next check and the failure is shown here in pink.
  • Kept: the last 14 daily copies, plus up to 4 weekly ones (never older than 28 days). Copies you make with BACK UP NOW, the safety copies made before a restore, and uploaded files are kept up to 28 days.
  • DOWNLOAD saves a copy as a file on this device: an off-site copy in case Cloudflare storage itself is ever lost. Keep it private (it holds every pilot's scores and purchases), and delete downloaded files older than 30 days, and any made before a privacy deletion, so the 30-day promise in the Privacy Policy holds for them too.
  • DRY RUN changes nothing. It shows what a restore of that copy would do: which stored parts would be added, changed or removed, and pilots, scores and purchases now versus after. Use it first, every time.
  • Real restore is only for a real accident: the boards were wiped, a bad update damaged scores, or purchases went missing. Type the phrase it shows (RESTORE and the backup's name) and press RESTORE NOW. The server first saves a safety copy of the leaderboard as it is now, then restores, then checks the result matches the backup. To undo a restore, restore that safety copy.
  • A restore puts the leaderboard back to that moment: scores and purchases made after it are lost. Purchases from the last 3 days are delivered again by the automatic payment check; older ones can be looked up in the purchase records under ADVANCED. Anonymous PLAYER STATS are not part of backups.
  • A privacy deletion also removes the pilot from every backup on the server, so a restore never brings them back.

Combined World Grid

  • What it does: the game's EARTH, MARS and JUPITER boards, the WORLD tab (country totals) and the grid on the gateway page show each pilot's best of Season 0 and Season 1, per difficulty. For a country, each pilot counts once at their best weighted score, exactly like today. Two scores are never added together.
  • Nothing is rewritten. The Season 0 archive and every Season 1 best stay exactly as stored; the combined grid is worked out from them. REVERT switches back to Season 1 only at any time, and APPLY switches it on again.
  • New storage only: the combined grid needs the storage move (STORAGE) done first. On the old layout the WORLD GRID buttons answer "Move the storage first" and change nothing.
  • Steps: (1) BACK UP NOW under BACKUPS. (2) DRY RUN: every check must say PASS, first of all no current score lost. Read the countries before and after and the flagged list. (3) If you approve, type the phrase it shows (APPLY and the dry run's name) within 60 minutes and press APPLY NOW. The server checks the backup, saves a safety copy, switches, then checks the live grid; if that check fails it switches back by itself. (4) Open the game's leaderboard and the gateway page: they say "Season 0 + Season 1".
  • Flagged entries are Season 0 scores that are left out, with the reason: the pilot no longer exists (score removed or deleted), was privacy-deleted, appears twice in the archive with different data, or the score is not valid. They are never guessed or brought back. Restricted pilots stay hidden, as today.
  • A pilot who changed name or country since Season 0 is shown under their current name and counts for their current country.
  • Free plan: the dry run reads each pilot once and writes nothing. APPLY is a one-off: it reads each pilot a few times and writes the Season 0 table once (about 4 rows per archived pilot — about 16,000 at 4,000 archived pilots, of the 100,000 a day). After that a run writes exactly the rows it writes today, and a restart never reads every pilot. REVERT writes 2 rows.
  • Season 0 Easy and Medium scores were earned at the old, higher point rates; with the combined grid they can count again. The dry run shows how many bests come from Season 0 on each difficulty.

Storage move (2 MB limit)

  • Why: the old layout stores every pilot in one value, and Cloudflare caps a value at 2 MB — about 8,000 pilots. STORAGE shows how full it is. Move before it passes about 75%.
  • 1. Back up. Press BACK UP NOW. The move refuses to start without a checked backup from the last 60 minutes.
  • 2. Dry run. Press DRY RUN. It builds the new layout in memory and compares everything with the old one — every pilot, best, cooldown, purchase (incl. Solar Inferno), #tag, restore code, the four leaderboards and the country totals — and shows PASS or FAIL for each, plus how many rows the move will write. It changes nothing. If anything says FAIL, stop and ask for help.
  • 3. Approve and move. Type the phrase it shows (MIGRATE and the dry run's name) and press MOVE NOW. The server takes a safety backup first, then copies the pilots in batches (a few seconds for 8,000 pilots). Players keep playing meanwhile. At the end it pauses everything for a moment, copies what changed, compares again, and only then switches. If a comparison fails it does not switch and FLUX stays on the old layout. If it stops half-way, press MOVE NOW again: it continues.
  • 4. Check. Press CHECK A SAMPLE, then CHECK EVERY PILOT. Each public answer (leaderboards, countries, skins, restore codes, #tags) is compared between the old and the new layout: PASS or FAIL. Pilots who played since the move are counted as changed, not as failures.
  • If the check fails: type ROLLBACK and press ROLL BACK. FLUX goes back to the old layout, keeping every score and purchase made since the move (a safety backup is taken first).
  • Later, once everything has run well for a while: CLEAN UP removes the old layout's copy (only after CHECK EVERY PILOT passed; a safety backup is taken first). After that, going back is only possible by restoring a backup.
  • Backups keep working on the new layout: they are copied page by page, and score uploads wait a few seconds while that happens (the game retries them by itself). A privacy deletion also removes the pilot from the old layout's copy and from every backup.

Reading PLAYER STATS

  • Active players: pilots who opened FLUX that day (each counted once). Monthly active: each counted once per calendar month.
  • New players: pilots seen for the first time that day.
  • Runs / player: finished runs ÷ active players, per day. Avg run: average length of a finished run. Avg level: average level reached at the end of a run.
  • Share rate: share-button taps ÷ finished runs. Home Screen: opens from the installed app.
  • Day 1 / Day 7 / Day 30: of the players who started on a date, the share who came back 1, 7 or 30 days later. "—" means that day has not come yet.
  • Which platform brings players who come back: choose By source (src). Each row is where players first came from (the ?src= tag in your link: tiktok, facebook, instagram, youtube, share for links players shared, direct for none). Compare their Day 7 and Day 30 columns — higher means that platform brings players who stay. Always post links with a tag, e.g. …/play/?src=tiktok.
  • Individual events are kept 90 days, then only totals. Nothing here identifies a person.

Reading GAMEPLAY (tuning the speed)

  • One row per difficulty and speed step of the ball (0 = the starting speed; the ball gets a little faster at each step, by run time). It is for everyone, whatever you choose under Group.
  • Runs: finished runs that reached that step. Time at step: total play time at that speed, and its share of all play time on that difficulty. If almost all the time is at step 0-1, players rarely get far.
  • Hit rate: orb hits ÷ (orb hits + wrong-colour hits). Misses / min: wrong-colour hits plus lost balls per minute at that step. Lives lost / min: lost balls per minute.
  • How to tune: if lives lost / min jumps between two steps, that step is too big a jump; if a difficulty loses lives quickly already at step 0, its starting speed is too fast. A steady hit rate with few lives lost at the top step means that difficulty could go a little faster. Compare Easy, Medium and Hard: each should lose lives faster than the one before at the same step.
  • Only totals by difficulty and step are kept here — no country, no source, nothing about a person.

FLUX COMMAND on your iPhone or iPad

  1. Open /admin.html on this site in Safari.
  2. Tap Share → Add to Home Screen → Add. The amber FLUX COMMAND icon opens this page full screen, separate from the game.
  3. Log in with the admin password. You stay logged in for 30 minutes without use and 12 hours at most; then it asks again. Anything you had typed on the page is kept. LOG OUT ends the session at once.
  4. It needs a connection. Offline it only says to reconnect; no admin data is kept on the device.

Locked out?

  • "Too many requests from this device" is the general admin speed limit (30 requests a minute); it lasts under a minute and never counts as a wrong password.
  • 5 wrong passwords from one device within 15 minutes lock that device for 15 minutes. The login screen says how long. Wait, then try again.
  • If many wrong passwords arrive from everywhere (50 in 15 minutes), a 15-minute safety mode starts in which one wrong password locks a device. A device that has not typed a wrong password can still log in, and you stay logged in where you already are.
  • Always works: in the Cloudflare dashboard open Workers & Pages → flux-sparta-3 → Settings → Variables and Secrets, edit ADMIN_TOKEN and save a new password. Every lock is cleared and every session is logged out at once. Log in with the new password.
